# Site assets

Replace or add files here when ready:

- `logo.svg` — transparent shared header/footer logo and favicon. Replace this file (and its references in the HTML pages and `js/main.js`) if you prefer another format.
- `hero.jpg` — home page hero background
- `covers/<record-id>.jpg` — album covers referenced in `js/products.js`

The site remains usable without these images: the logo falls back to the text wordmark, the hero uses its dark gradient, and album covers show the CSS vinyl placeholder.
